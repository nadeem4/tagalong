Pair Tagalong with this browser

Open Tagalong on this computer, go to Settings → Browser extension, copy the pairing token, and paste it here. You only do this once.

Reading tabs

By default the extension can read a tab only after you use it there — the toolbar button, the shortcut, or the side panel. Turn this on to let it read whichever tab is in front when you ask, including from the desktop hotkey. It still reads nothing until you ask.

Connection: checking…

The extension needs the Tagalong desktop app running on this computer. It talks only to 127.0.0.1 and stores the token in this browser's local extension storage.
